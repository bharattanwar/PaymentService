# Payment Gateway Service

Welcome to the Payment Gateway Service repository! This service integrates with Razorpay and Stripe platforms to handle payments efficiently and securely.

## Overview

The Payment Gateway Service is designed to facilitate seamless payment processing using two popular payment gateways: Razorpay and Stripe. It is built using Java 17, Spring Boot 3.3.0, and Spring Cloud 2023.0.2. This service allows for secure and reliable transactions, catering to various payment needs.

## Features

- **Razorpay Integration:** Process payments through Razorpay with ease. Supports various payment methods, including credit/debit cards and net banking.
- **Stripe Integration:** Handle payments via Stripe, offering support for a wide range of payment options such as cards, wallets, and more.
- **Transaction Management:** Track and manage payment transactions effectively.
- **Secure Payment Handling:** Utilize industry-standard security measures to ensure safe transactions.

## Getting Started

To get started with the Payment Gateway Service, follow these steps:

### Prerequisites

- Java 17
- Maven 3.8.1 or higher
- MySQL database
- Razorpay and Stripe account credentials
